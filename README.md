## Catatan metodologi
- Setiap notebook berisi ringkasan teori, demonstrasi kode, interpretasi, dan kesimpulan.
- Untuk Bab 7–10, beberapa kode dibuat sebagai ilustrasi konsep yang dapat dijalankan dengan NumPy; kode tersebut tidak diklaim sebagai salinan persis seluruh listing kode di buku.
- Bab 8 di buku menggunakan eksperimen klasifikasi MNIST. Notebook ini menggunakan data sintetis untuk menunjukkan konsep generalisasi, mini-batch, regularisasi, dan dropout tanpa memerlukan unduhan dataset atau TensorFlow/Keras.
- Jalankan notebook secara berurutan dari atas ke bawah. Beberapa eksperimen yang menggunakan angka acak memiliki seed agar hasil lebih konsisten.
